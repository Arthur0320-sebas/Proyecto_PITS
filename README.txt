PITS ADMIN - COMPARTIDO Y GUARDADO REAL

ESTA ES LA VERSIÓN QUE NECESITAS PARA COMPARTIR EL SISTEMA.

Qué hace:
- Conserva todos tus datos actuales.
- Al abrir desde el servidor, todos los cambios se guardan en data/state.json.
- Si dos personas entran al mismo servidor, ambas ven la misma información al recargar.
- Ya no depende solamente del localStorage de un navegador.

PARA USARLO EN TU COMPUTADORA:
1. Descomprime la carpeta.
2. Abre la carpeta en Visual Studio Code.
3. En Terminal ejecuta: npm install
4. Después ejecuta: npm start
5. Abre http://localhost:3000

IMPORTANTE SOBRE COMPARTIRLO POR INTERNET:
localhost SOLO funciona en tu propia computadora. Para que tu papá u otro dispositivo puedan entrar desde fuera, hay que publicar esta misma carpeta en un hosting que ejecute Node.js (por ejemplo Render, Railway o un servidor propio).

Esta versión ya está preparada como servidor Node.js para ese siguiente paso.
